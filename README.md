# Distributed Systems (ID2201)

Repository for labs and assignments in KTH Course ID2201 - Distributed Systems.

## Projects

- **[Routy](./Routy)**: A distributed link-state routing protocol implementation in Erlang.
- **[Loggy](./Loggy)**: A distributed logging system where workers exchange messages and send log entries to a central logger.
- **[Groupy](./Groupy)**: A distributed group membership service where members (processes) stay coordinated through atomic multi-casting.
- **[Chordy](./Chordy)**: A distributed hash table for peer-to-peer data storage and access.
